# LLM-Powered Data Intelligence Projects

A collection of advanced applications leveraging Large Language Models to unlock value from both structured and unstructured data.

---

## 📚 Projects

### 1. **City Council Community Assistant** (RAG Application)

**Problem:** Community members lack easy access to accurate meeting information, leading to rumors, misinformation, and reduced civic engagement.

**Solution:** A Retrieval Augmented Generation (RAG) system powered by Cortex Search that intelligently indexes unstructured meeting minutes and documents, enabling citizens to ask natural language questions and receive instant, accurate answers grounded in official records.

---

### 2. **Text-to-SQL Intelligent Context-Aware SQL Generation**

**Problem:** Business users wait hours for analysts to write custom queries; state-of-the-art LLMs fail at semantic complexity (missing joins, returning unreadable numerical IDs, no error validation).

**Solution:** A multi-agent agentic workflow powered by Cortex Analyst that understands semantic context, validates SQL syntax/semantics, handles complex joins automatically, and returns human-readable results in seconds—democratizing data access for non-technical users.

---

## 🛠️ Tech Stack

Both projects leverage Snowflake's Cortex capabilities:
- **Cortex Search** — Intelligent retrieval over unstructured data
- **Cortex Analyst** — Semantic-aware SQL generation with error correction
- **Cortex LLM** — Advanced language understanding and generation
- **Snowflake Notebooks** — Unified development environment
